# Smoke-задание (не ревью)

Сделай ровно это и ничего больше:
1. Выполни `pwd`, `git log --oneline -3`, `git status --short`.
2. Запусти тесты: `.venv/bin/pytest -q`.
3. Создай файл `smoke.txt` в текущем каталоге с одной строкой `ok`.
4. Финальным сообщением дай отчёт из 5 строк: pwd; последний коммит; вывод git status; результат pytest (сколько прошло); удалось ли создать файл.
